# Lost Souls

2D-игра на собственном движке SEC-Engine (C++ / Python): замок, исследование залов, инвентарь и LAN-мультиплеер.

Этот репозиторий — только официальная страница загрузки. Исходного кода игры здесь нет.

## Скачать

Все версии — на странице [Releases](https://github.com/mmobik/lost-souls/releases).

1. Скачайте архив `LostSouls-<версия>-windows-x64.zip` и распакуйте в любую папку.
2. Запустите `LostSouls.exe`. Сохранения и настройки создаются рядом с игрой в папке `user_data/`.
3. Игра пока не подписана цифровой подписью: Windows SmartScreen может показать предупреждение — нажмите «Подробнее» → «Выполнить в любом случае».

## Системные требования

- Windows 10/11, 64-bit
- Видеокарта с поддержкой OpenGL 3.3

## Мультиплеер

Игра по локальной сети: один игрок создаёт игру в меню «Мультиплеер», остальные подключаются по IP. Брандмауэр Windows спросит разрешение — разрешайте только для частных сетей.
